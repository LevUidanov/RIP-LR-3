# ЛР-3. Простое веб-приложение

- Студент: Уйданов Лев Алексеевич
- Группа: ИБМ3-54Б
- Дисциплина: Разработка интернет-приложений

## Описание

Двухстраничное приложение на JavaScript с Bootstrap в стиле ФК Спартак Москва. Главная страница: карточки игроков основного состава и группа кнопок (фильтр по позиции). Вторая страница: информация об игроке и кнопка "Назад". Вариант 7, компонент: группа кнопок.

## Исходный код

Весь код проекта в архиве [RIP-LR-3-code.zip](RIP-LR-3-code.zip), текст программы также приведен в отчете.

## Запуск

0. Распаковать архив.
1. Установить зависимости: `npm i`
2. Открыть папку в VS Code и запустить `index.html` через расширение Live Server (кнопка Go Live). Двойным кликом по файлу страница не откроется, так как скрипты подключены как модули.
